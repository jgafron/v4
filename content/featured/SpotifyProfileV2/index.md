Built an embedded wireless packet capture system using an Adafruit Feather RP2040, a LoRa radio, an AirLift WiFi module, and an OLED display. I wrote the firmware to monitor wireless traffic, capture packet metadata like RSSI and timestamps, and export the data for analysis in Wireshark. Along the way, this doubled as a hands-on exercise in passive hardware reconnaissance and PCAP generation for IoT security investigations.
